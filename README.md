# Love Heart Animation 💖

A Python script that generates a beautiful, animated heart shape using the `turtle` graphics library. The heart is dynamically drawn on a dark canvas using the phrase "I love you" translated into multiple languages.

## Features
* **Multilingual Text:** Displays "I love you" in languages like Spanish, German, Korean, Japanese, and more.
* **Smooth Animation:** Watch the heart dynamically form in real-time.
* **No External Dependencies:** Built entirely with standard Python libraries (`turtle`, `tkinter.font`, `math`, `random`).

## Prerequisites
* Python 3.x installed on your system.
